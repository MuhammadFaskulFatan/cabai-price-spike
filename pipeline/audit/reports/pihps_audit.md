# Audit PIHPS (harga harian, bulanan hasil hitung sendiri)

Periode data 2018-01 sampai 2026-11 (November 2026 parsial). Periode inti 2019-01 sampai 2026-10 (94 bulan). Bulan dianggap valid kalau minimal 10 hari kerja terisi. Survei PIHPS hanya Senin-Jumat, sehingga file harian berisi kolom hari kerja saja.

- File harian: 18 kombinasi tipe harga x komoditas; 1,315,230 sel harian.
- Baris provinsi di data yang tidak ada di referensi 34 provinsi: ['Dum']. Baris ini dikeluarkan dari tabel di bawah dan dicatat sebagai anomali sumber (bagian 8).
- Baris yang tidak muncul di respons (misalnya provinsi tanpa data harga produsen) diperlakukan sebagai seri kosong (nol hari).
